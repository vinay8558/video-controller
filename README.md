# Video Controller

A Chrome extension that lets you speed up or slow down **any** video on **any** website — YouTube, Netflix, Amazon Prime, and everything else.

## What you get
- A floating speed badge on top of every video (drag it wherever you want)
- A popup with a slider and quick presets (0.5x / 1x / 1.5x / 2x / 3x)
- Keyboard shortcuts: **Alt+D** faster · **Alt+S** slower · **Alt+R** reset
- Your speed is remembered across tabs and sites

## How to install

1. Click the green **Code** button above → **Download ZIP**.
2. Unzip it somewhere you won't move (e.g. `Documents/video-controller`).
3. Open Chrome and go to `chrome://extensions`.
4. Turn on **Developer mode** (top-right toggle).
5. Click **Load unpacked** and select the folder you unzipped.
6. Done — open any video and you'll see the speed badge appear.

Works the same in Edge and Brave (`edge://extensions` / `brave://extensions`).

## How to use

- **Speed up / slow down** — click `+` / `−` on the floating badge, use the popup slider, or press Alt+D / Alt+S.
- **Reset** — click `R` on the badge or press Alt+R.
- **Move the badge** — click and drag it.
- **Turn it off** — open the popup (click the extension icon) and flip the toggle.
